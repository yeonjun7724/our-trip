# 철도 연동

## TAGO 열차정보 (data.go.kr 15098552)

- Base: `https://apis.data.go.kr/1613000/TrainInfo`. 예전 경로인 `TrainInfoService`는 2026-11-18 기준 `NO_OPENAPI_SERVICE_ERROR`를 돌려줍니다.
- 오퍼레이션 이름은 공식 페이지에 영문으로 나오지 않아 **게이트웨이에 직접 호출해 확인했습니다**. 존재하는 경로는 키 오류 403,
  없는 경로는 400을 돌려줍니다. 확인한 이름은 `GetCtyCodeList`, `GetCtyAcctoTrainSttnList`, `GetVhcleKndList`, `GetStrtpntAlocFndTrainInfo`이고 대문자로 시작합니다.
  (버스 API는 소문자 `get…`, 지하철 `SubwayInfo`는 대문자 `Get…`입니다.)
- 응답 필드명(`trainno`, `traingradename`, `depplandtime`, `arrplandtime`, `depplacename`, `arrplacename`, `adultcharge`)도
  공식 페이지에 나오지 않습니다. 그래서 값이 없어도 깨지지 않게 방어적으로 파싱합니다. **실제 키로 검증해야 합니다** (`scripts/check_providers.py`).
- 역은 공식 역 ID(nodeid)와 표시 이름을 따로 다룹니다. 이름만 같다고 같은 역으로 보지 않습니다.
- 운임(`adultcharge`)은 공급자가 줄 때만 "(API 제공)"을 붙여 표시합니다. 잔여석과 지연은 제공되지 않으므로 표시하지 않습니다.
- 결과 없음은 `NO_TRAINS` 상태로 돌려주고, 날짜가 공급 범위 밖이거나 직통편이 없을 수 있다고 안내합니다.
  인증 실패, 한도, 잘못된 요청, 장애는 각각 별도 오류 코드로 돌려줍니다.

## 환승 후보 — `GET /api/rail/transfer-candidates`

사용자가 고른 환승역으로 두 구간을 따로 조회한 뒤, `도착 + 최소 환승시간 ≤ 다음 출발`이고 대기가 2시간 이하인 조합 중
가장 빠른 다음 열차를 붙입니다. 결과는 "후보"로만 표시하고 실제 환승 가능 여부는 보장하지 않는다고 안내합니다.

## 한국철도공사 운행정보 (15125762)

Base `https://apis.data.go.kr/B551457/run/v2`. 운행계획 조회는 3개월 전부터 1개월 뒤까지를 지원합니다. 이번 구현에서는
TAGO로 충분해 **어댑터를 만들지 않았습니다**. 필요하면 `providers/`에 추가하면 됩니다.

## 열차 기록과 연결 검토

- 시간표에서 고른 열차는 `schedule_source=TAGO_TIMETABLE`과 조회 시각으로 저장합니다. 직접 입력한 열차는 `USER_ENTERED`로 저장하고 "시간표 미확인"으로 표시합니다.
- 예매 상태는 `PLANNED`(예매 전), `RESERVED`(사용자가 예매 완료로 표시), `CANCELLED`입니다. 앱이 예매했다고 표시하는 일은 없습니다.
- 열차를 기록하면 같은 날짜의 일정에 RAIL 항목(고정)으로 들어갑니다.
- 역의 지도 위치는 OSM 역 후보 중에서 사용자가 골라 확정합니다. 이는 위치를 연결할 뿐, ID를 같은 것으로 보는 것은 아닙니다.
- 연결 판정 규칙은 `역 도착 예상 + 사용자 여유시간 ≤ 출발`입니다. 결과는 다음 중 하나입니다.
  연결 가능성이 높은 계획 / 여유시간 부족 / 열차 출발 이후 도착 예상 / 연결 조건 미확인 / 시간표 미확인 / 데이터 부족.
  여유시간 기본값 20분은 공식 규정이 아니라 사용자가 정하는 계획 버퍼라고 화면에 적어 둡니다.

## 내일로

코드는 서로 다른 탑승일 수를 세서 선택 3일권이면 3일 초과를, 연속 7일권이면 첫 탑승일부터 마지막 탑승일까지 7일 초과를 경고합니다.
3박 4일 동안 4일 모두 열차를 타면 선택 3일권으로는 하루가 부족하다는 경고가 나옵니다(테스트로 확인).
공식 내일로 안내 페이지는 개발 중 404여서 **연령, 이용 가능 열차, 좌석 지정, 선택 기간 규칙은 코드에 넣지 않았습니다.**
화면에서는 코레일 공식 안내를 확인하도록 안내합니다.
