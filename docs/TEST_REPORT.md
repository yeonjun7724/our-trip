## E2E — Playwright (Chromium)

| 대상 | 결과 |
|---|---|
| 로컬 (http://127.0.0.1:8000, 빌드된 SPA + 실제 그래프) | 7/7 통과 |
| Railway 운영 URL (HTTPS) | 2/2 통과 (협업 흐름, 390px) |

협업 흐름에서 확인한 것: 휴대폰 두 대를 흉내 낸 별도 컨텍스트로 여행방 생성 → 초대 링크 → 참여 → 상대가 네이버 공유 문구 붙여넣기(이름 힌트, 좌표 없이 저장) →
주인이 투표 → "둘 다" 탭에 동기화 → 지도 마커 → Bottom Sheet → OSMnx 도보 경로(4.7km) → ODsay 미설정 안내와 외부 링크 →
주변 정류장(OSM과 실제 보행거리) → DAY 1 배정 → 일정 09:00 → 상대가 방문 체크 → 주인 화면에 반영 → 열차 직접 기록("직접 입력", "예매 전") → 제3자 비인증.

반응형: 360, 375, 390, 430, 768, 1280px에서 화면 9개(홈, 위시, 일정, 교통 3탭, 지도, 장소 추가, 설정) 모두 가로 스크롤이 없고, 하단 메뉴 터치 영역이 44px 이상입니다.
스크린샷은 `apps/web/e2e-results/`에 있습니다(git에서 제외).
