# 외부 API·데이터 이용 정책

이 문서는 코드가 실제로 지키는 규칙을 적습니다. 공급자 약관이 바뀌면 이 문서와 설정값을 함께 갱신합니다.

## 공통 원칙

- 외부 교통 API는 **사용자가 버튼을 눌렀을 때만** 호출합니다. 장소 추가나 최적화 때 자동으로 대량 호출하지 않습니다.
- 동일 요청이 동시에 들어오면 하나로 합칩니다(in-flight merge). 공급자별로 분당 호출 상한과 최소 간격을 두고,
  429나 한도 초과가 오면 60초 동안 쉽니다. 5xx와 네트워크 오류는 지수 백오프(0.6초, 1.2초)로 최대 3번 시도합니다.
- `api_usage_logs`에는 공급자, 분류, 상태코드, 결과, 지연시간만 남깁니다. **API 키, 좌표, 요청 파라미터는 기록하지 않습니다.**
- 공급자 원본 응답을 저장하는 테이블은 없습니다. 사용자가 고른 경로는 `transport_legs`에 **요약**(이동수단, 분, 환승 수,
  노선 문자열, 공급자, 조회 시각)만 저장합니다. 사용자 자신의 일정 기록이기 때문이고, 3일이 지나면 STALE로 표시합니다.
- 키가 없거나 비활성화된 공급자는 해당 기능만 "미설정"으로 표시합니다. 가짜 값을 실제처럼 보여주지 않습니다.
- `VERIFIED` 상태는 서버 인스턴스가 실제 정상 응답을 받은 뒤에만 표시합니다. 키만 있으면 `CONFIGURED_UNVERIFIED`입니다.

| Nominatim | 초당 1회 이하, 식별 가능한 User-Agent, 자동완성 금지 | 검색 버튼을 누를 때만 호출. 전역 1.1초 간격. 하루 메모리 캐시 |

## 네이버·카카오 공유 링크

- 사용자가 붙여 넣은 URL은 **북마크**(`original_share_url`)로 저장합니다.
- 장소 ID는 URL에 드러나 있을 때만 추출해 `provider_place_id`에 둡니다. 원래 링크로 돌아가기 위한 용도입니다.
- 짧은 링크(naver.me, kko.to)는 허용 목록의 호스트에 한해 **리다이렉트 Location 헤더만** 읽어 펼칩니다. 본문은 읽지 않습니다.
- 페이지 스크래핑, 내부 API 호출, 로그인 쿠키 사용, 검색 API 결과(이름·주소·좌표) 복사는 하지 않습니다.
- 이름 힌트는 **사용자가 붙여 넣은 공유 문구**에서만 가져오고, 사용자가 확인하거나 수정합니다.
- 좌표는 우리 OSM 지도에서 사용자가 직접 찍은 값(`USER_PICKED`)이나 Nominatim 검색 결과(`OSM_NOMINATIM` + osm_ref)만 받습니다.
  API도 그 외 출처의 좌표는 거부합니다(422).
